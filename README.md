# donate-bangladesh

**Live Demo:** [https://siyam-donate-bangladesh.vercel.app/](https://siyam-donate-bangladesh.vercel.app/)

Donate Bangladesh is a web-based donation portal designed to assist relief efforts and gather support for disaster-stricken areas in Bangladesh, including flood relief in Noakhali, Feni, and quotas movement injured support.

## Core Features
- Interactive, responsive UI built with TailwindCSS and DaisyUI.
- Real-time balance deductions on donation.
- Clean and intuitive card-based layout.
- Complete transaction/donation history tracking.
- Interactive modal feedback upon successful donations.
- Dynamic navigation to a FAQ blog page.

## Tech Stack
- HTML5
- TailwindCSS & DaisyUI
- JavaScript (Vanilla DOM Manipulation)
- Font: Lexend (Google Fonts)
